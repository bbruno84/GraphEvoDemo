# GraphEvoDemo feature guides

This section documents how GraphEvo is implemented and exercised by the demo
application. Each guide combines a technical reference, a wiki-style map of the
relevant code, and a tutorial-style example that can be run from the app.

## Available guides

- [V01 T0 mirroring control](v01-control.md)
- [Framework laboratory](framework-laboratory.md)
- [GraphEvo feature coverage](graph-evo-coverage.md)

## Scope

The demo currently focuses on the graph model, persistence, queries, tags,
groups, relationships, actions, watchers, and CloudKit lifecycle diagnostics.
Migration implementation and migration-specific examples are intentionally out
of scope for the current development cycle.
